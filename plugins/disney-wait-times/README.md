# Disney Wait Times for Universal LED Scoreboard

Displays Walt Disney World attraction standby waits from the ThemeParks Wiki REST API on a 64×32 panel. No API key or matrix driver dependency required. Install through the ULS Plugin Manager and configure park, display duration, refresh interval and maximum wait. Shows two attractions per page, sorted by wait time. The source API may change and is not affiliated with Disney. Failed requests retain last known data with a red status pixel. Network requests use a four-second timeout.
